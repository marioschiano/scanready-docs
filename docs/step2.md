## Why Regenerate the Scan's UVs

UVs created by the original scan are not always suitable for an optimized mesh. They are often highly fragmented, with many small islands, and do not use the entire **0-1** texture space efficiently.

This can leave large empty atlas areas, distribute texel density poorly and make baking harder to control. After mesh reduction, the old layout may no longer describe the new low-poly surface ideally.

ScanReady therefore generates a tidier, more compact UV layout. Islands are reduced and packed more efficiently so the optimized surface can make better use of the texture and receive detail transferred from the high-poly scan.

---

A simplified mesh is lighter and easier to manage, but still needs consistent texture coordinates.

UVs define how a 3D model's surface is unfolded into 2D texture space.

After reduction, the scan's original UVs should no longer be considered reliable on the optimized mesh.

Because geometry has been combined and simplified, the original UV layout can become:

- stretched;
- distorted;
- overlapping;
- messy;
- misaligned with the new low-poly surface.

In the ScanReady workflow, use **Generate UVs** to prepare the mesh intended for baking. The new layout should have well-separated islands and adequate texture space: check it before proceeding.

## Better Use of UV Space

New UVs also improve texture-space efficiency.

Many photogrammetry scans contain UV layouts that waste large portions of the 0-1 texture space.

After optimization, ScanReady can generate a cleaner UV layout with better packing and more efficient texture usage.

<p align="center"><img src="../img/step2-uv-packing-efficient.jpg" alt="Optimized UV packing in a single atlas to reduce draw calls and simplify export" style="max-width:1000px;width:100%;" loading="lazy" decoding="async"></p>

This allows the optimized asset to retain more detail using fewer materials and less texture memory.

Good UVs help achieve:

- cleaner baked textures;
- better texture sharpness;
- fewer visible seams;
- better realtime performance;
- more reliable results in game engines.

---

## Textures Replace Geometry

The goal of baking is to preserve the visual richness of the original scan while reducing polygon density.

Instead of keeping millions of polygons, ScanReady transfers visual surface information into textures.

This allows the optimized mesh to remain lightweight while retaining much of the original appearance.

## Why the Cage Is Needed

The cage controls how Blender projects details from the high-poly scan onto the optimized mesh during baking.

If the cage is too small:

- some details may not be captured;
- black areas may appear;
- projection errors may appear.

If the cage is too large:

- the bake may capture unwanted nearby surfaces;
- projection artifacts may appear.

ScanReady includes tools to make this process faster and easier.

## UV Method

ScanReady uses **Smart UV Project** to generate UVs on the optimized mesh.

Smart UV Project is Blender's automatic UV unwrap method.

It is useful for scanned objects because it can quickly generate UV islands without requiring manual seams.

ScanReady exposes Smart UV controls so you can adjust unwrap behavior before baking.

## UV Settings

**Smart UV Preset** is in **Step 2** (compact label **Smart UV**). **Smart UV Angle** and **UV Padding** are in **Advanced > UV Settings**.

### Smart UV Preset

<div class="sr-doc-row" style="display:flex; flex-wrap:wrap; gap:28px; align-items:flex-start; margin-top:16px; margin-bottom:28px;">
<div style="flex:1 1 0; min-width:0;">
<p>ScanReady uses Blender Smart UV Project for automatic UV generation.</p>
<p>Available Smart UV presets include <strong>Detailed</strong>, <strong>Balanced</strong>, <strong>Large Islands</strong> and <strong>Continuous</strong>.</p>
<ul>
<li><strong>Balanced</strong>: a compromise between island size, texel density and UV space usage. Recommended in most cases.</li>
<li><strong>Detailed</strong>: creates more islands and follows the surface more precisely, useful for better preserving local mesh variations.</li>
<li><strong>Large Islands</strong>: favors larger, less fragmented UV islands. It can look similar to Balanced, but tends to reduce the island count further even when packing is less uniform.</li>
<li><strong>Continuous</strong>: favors more continuous, coherent islands along the surface, useful for limiting layout breaks and fragmentation.</li>
</ul>
<p>UV controls affect how the optimized mesh is unwrapped before baking. They are separate from Adaptive Reduce, which controls mesh simplification in Step 1.</p>
</div>

### Smart UV Angle

Controls how aggressively Smart UV Project divides the mesh into islands.

Lower values create more cuts and more UV islands.

Higher values create larger UV islands.

### UV Padding

Sets the space between UV islands.

Increase padding to reduce texture bleeding, especially at lower texture resolutions.

## Cage Controls

### Show Cage

Shows the cage preview.

Use it before baking to check that the cage generated from the optimized mesh covers the high-poly surface to be sampled.

### Auto Cage Extrusion

Automatically estimates cage extrusion by sampling the distance between the optimized mesh and original high-poly scan.

It is useful for a quick starting point without manually guessing cage distance.

### Cage Extrusion

Manually controls cage distance.

Increase it if the bake loses detail, creates black areas or produces projection errors.

Use the smallest value that correctly covers the scan surface.

<p align="center"><img src="../img/step2_cage_extrusion.gif" alt="Example of Cage Extrusion in ScanReady" style="max-width:1100px;width:100%;" loading="lazy" decoding="async"></p>

### Cage Opacity

Controls cage preview opacity.

It affects only the viewport display and does not change the bake result.

## When to Regenerate UVs

!!! note "When to click Generate UVs"
    Click **Generate UVs** after creating or updating the low-poly preview.

    If you change **Smart UV Preset**, **Smart UV Angle** or **UV Padding** after generating UVs, click **Generate UVs** again to apply the new UV settings. **Bake Textures** uses the UV layout existing at bake time.

    If you are in Step 2 and decide the optimized mesh is still too heavy, return to **Step 1 - Preview / Reduce**. Lower **Final Faces** or **Optimize / Reduce**, then return to Step 2 and click **Generate UVs** again so the UV mesh matches the new optimization.

Then check:

- UV layout;
- checker preview;
- cage coverage;

before continuing to:

[Step 3 - Bake / Output](step3.md)

---

## What to Check

Before baking, verify that:

- UVs are generated on the optimized mesh;
- UV islands are packed correctly;
- the checker pattern does not show extreme stretching;
- UV islands have enough padding;
- the cage completely covers areas that need baked detail;
- the cage is not so large that it captures unwanted nearby surfaces.

---

## Realtime Optimization

For VR and video game workflows, UVs and baking allow a lightweight model to still appear very detailed.

The optimized mesh should preserve important visual information through textures rather than millions of polygons.

Good UVs and a properly configured cage help keep the asset:

- lighter;
- easier to render;
- easier to export;
- more reliable in realtime engines;
- visually closer to the original scan.
