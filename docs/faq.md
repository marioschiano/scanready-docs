# FAQ

Quick answers to common questions. For full checks see [Troubleshooting](troubleshooting.md).

## Which Blender version is required?

ScanReady is a Blender Extension and requires **Blender 4.2 or later**. Download the package from the purchase platform and follow the [Installation](installation.md) page.

## Does ScanReady modify the original scan?

Reduction takes place on a separate preview. Preparation, however, can modify the high-poly: combining parts, applying scale, correcting normals, cleaning fragments or converting materials depending on enabled options.

Save a copy of the original file before Step 1, especially for scans intended for archiving.

## Do I need to set both Final Faces and Optimize / Reduce?

No. They are two linked controls for the same reduction: **Final Faces** indicates the face target, while **Optimize / Reduce** indicates the proportion of geometry to keep. Use whichever is more convenient; a ratio of `0.10` keeps approximately 10% of the polygons.

## Why do the UVs overlap?

Check the UV mesh layout, not the high-poly source layout. Very small fragments or problematic geometry can make unwrapping more difficult.

1. Check the preview and remove only unwanted fragments.
2. Try another **Smart UV Preset** or adjust **Smart UV Angle**.
3. Check **UV Padding** and press **Generate UVs** again.

Padding separates islands; it does not by itself correct distortion within them.

## Why does the bake look blurry, noisy or dirty?

The solution depends on the defect:

| Problem | First check |
|---|---|
| Blurry texture | Output resolution, source quality and UV space usage. |
| AO noise | **AO Samples** in **Advanced > Bake Settings > Occlusion Settings**. |
| Black areas or incorrectly projected details | **Show Cage**, cage distance, normals and source materials. |
| Oversimplified silhouette | **Final Faces**, **Optimize / Reduce** and the adaptive preset. |

Increasing samples does not add detail to a poorly defined source texture. Change one parameter at a time and compare the result.

If you already use a high resolution, even 8K, but detail is still insufficient, try increasing **Bake Materials**: more materials divide the surface across more textures and can preserve more detail.

## Do One Click Bake and Bake Textures do the same thing?

No. **One Click Bake** automatically performs multiple workflow steps, while **Bake Textures** uses the already prepared UVs, cage and settings to perform the bake. Use **Bake Textures** when you only want to repeat the bake after changing cage, margins or texture settings.

## Why is GPU baking still slow?

Resolution, number of materials, enabled maps and source complexity affect baking time. Also check **Force CPU Baking**: ScanReady enables it automatically when **Bake Materials** is set to `2` or more.

For testing, use smaller textures and only the necessary maps. Reduce samples for the relevant map; increase quality after checking the workflow.

## Where is my bake folder?

After a bake with **Save Images** enabled, open **Step 3 - Bake / Output** and press **Bake Folder**.

ScanReady opens the folder containing textures generated by the last bake.

To open the folder automatically after baking, enable **Open Folder After Bake** before pressing **Bake Textures**.

If **Bake Folder** still shows **No bake folder yet**, first perform a bake with **Save Images** enabled and check that **Output Folder** is valid.

## Why does the low-poly mesh look too smooth?

If shape detail is missing, increase **Final Faces** or **Optimize / Reduce**, or try the **Preserve Details** preset. Then update the preview.

A Normal Map can reproduce the appearance of small details, but cannot reconstruct a silhouette removed by reduction.

## I used One Click Bake, but the final model is still too heavy. What should I do?

You can return to Step 1 even after UVs and baking:

1. Adjust **Final Faces** or **Optimize / Reduce**.
2. Press **Create Lowpoly Preview** and check silhouette and wireframe.
3. Press **Generate UVs** in Step 2.
4. Check the cage.
5. Repeat **Bake Textures** in Step 3.

!!! tip "Choose the preset based on shape"
    Try **Flat Surfaces** for broad surfaces, panels and mechanical objects. Use **Fast Adaptive Reduce** for quicker testing of dense scans and disable it for the final quality check.

## Why are seams visible in the baked texture?

Check both **UV Padding**, which separates islands, and **Bake Margin**, which extends baked pixels beyond island edges. Resolution, compression and lighting already present in the source texture can also make seams visible.

If you change UV Padding, regenerate UVs and repeat the bake. If you change only Bake Margin, repeat the bake on the existing layout.

## I changed Smart UV Preset, but don't see a difference

After changing **Smart UV Preset**, **Smart UV Angle** or **UV Padding**, press **Generate UVs** again. The new settings do not automatically modify the existing UV layout.

When changing settings that affect the cage, repeat **Bake Textures** before evaluating the result. The previous bake is not updated automatically.

## I changed the cage, but the bake looks the same

Check **Show Cage** and **Cage Extrusion**, then press **Bake Textures** again. The command uses the current cage and UVs only in the new bake.

## Why does ScanReady recommend more bake materials?

More materials can provide more texture space for large scans. The **Analyze Texture Detail** recommendation is an estimate based on source textures and the UV layout, not a guarantee of the result.

Consider the memory cost and the number of materials required by the target platform. More polygons alone do not fix a poorly defined texture.

## When should I enable Convert Source Materials?

Leave it disabled if the bake is correct. Try it if Base Color is black, incomplete or inconsistent and the problem comes from imported materials.

Enable **Convert Source Materials** in **Advanced > Mesh Settings**, press **Create Lowpoly Preview** and check the materials before baking again. Materials that are already standard are preserved.

## Does Save Preset also save the model?

No. It saves workflow parameters, including the output folder, but not scene objects or images. Use the `.blend` file to preserve the project.

After **Reload Preset**, check Output Folder and regenerate the steps affected by the new settings.

## Why does the optimized mesh look different from the original scan?

Reduction removes geometry, so some differences are inevitable. Check the model at the intended viewing distance and also compare materials and lighting.

If differences concern shape, increase density. If they concern color or surface detail, check UVs, cage and textures before adding polygons.
