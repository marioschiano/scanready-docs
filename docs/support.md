## When Contacting Support

Include:

- Blender version;
- ScanReady version;
- a screenshot of the issue;
- a brief description of the issue;
- steps to reproduce it;
- GPU, VRAM and RAM information if the issue concerns performance or memory.

This helps identify problems more quickly.
